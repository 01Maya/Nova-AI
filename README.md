# ✨ NOVA AI — Intelligent Workspace

## 📌 Overview

NOVA AI is a modern, responsive landing page for an AI-powered productivity workspace. It introduces a smarter way to organize tasks, manage ideas, and simplify everyday workflows through a clean and engaging user experience.

## 📝 Description

This landing page combines a minimal visual style with smooth motion, interactive elements, and a polished layout. It features animated text reveals, scroll-triggered section animations, magnetic buttons, smooth carousel transitions, animated statistics, and navigation that 
moves smoothly between page sections.

Soft gradients, scenic imagery, and thoughtful spacing create a premium SaaS aesthetic, while the responsive layout keeps the experience consistent across desktop, tablet, and mobile devices.

## 🚀 Features

- 📱 **Fully Responsive** — Adapted for desktop, tablet, and mobile screens.
- ✨ **Scroll Reveal** — Sections animate into view as users scroll through the page.
- 🔤 **Word Reveal** — Headings appear with staggered word-by-word animations.
- 🧲 **Magnetic Buttons** — Interactive buttons respond subtly to pointer movement.
